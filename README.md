# RRVentures Admin Dashboard

## Overview

RRVentures Admin Dashboard is a modern and responsive frontend web application designed to help administrators manage services, advertisements, and website content through an intuitive interface.

The project is inspired by service-management platforms such as Urban Company and focuses on providing a clean, professional, and user-friendly admin experience.

## Features

### Authentication

* Login Page
* Signup Page
* Responsive Authentication UI

### Dashboard

* Overview Statistics Cards
* Sidebar Navigation
* Quick Access Interface
* Responsive Layout

### Services Management

* View Services
* Add New Services
* Edit Service Information
* Delete Services
* Search Functionality

### Advertisements Management

* Upload Advertisement Images
* Add Advertisement Title
* Add Advertisement Description
* Edit Advertisements
* Delete Advertisements
* Title Length Validation (Maximum 30 Characters)

### Customization

* Company Information Management
* Website Description Management
* Content Customization Interface


2. Open the project folder

```bash

```

3. Run the project using a browser or Live Server.
